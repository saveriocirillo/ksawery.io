## Portfolio

[KRKplaysTennis API docs](/portfolio/) is a documentation portal I built for a fictional API that rates amateur tennis players in Kraków from real match results. It shows how I write and how I work: the OpenAPI spec comes first, every page goes through a reviewed pull request, every code sample runs against a mock server, and the docs work for AI agents as well as people. The source is on [GitHub](https://github.com/saveriocirillo/krk-plays-tennis-docs).
